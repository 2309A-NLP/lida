# RAG 多角色智能聊天机器人 - 优化文档

## 项目概况

基于 RAG (Retrieval-Augmented Generation) 架构的多角色智能聊天机器人，支持多角色切换、知识库检索增强、流式对话等核心功能。

## 优化状态概览

- 当前服务状态：运行正常（端口 8080）
- 本次修复优化：4 项（单例模式、禁用非必要模型加载、API Key 配置、检索方案切换）
- 待实施优化：6 项（向量检索、Milvus、Redis 缓存、流式响应、打字机效果、连接池）

## 技术栈

- 后端框架：FastAPI
- 检索方案：jieba 分词 + BM25 关键词匹配
- AI 模型：DeepSeek API（远程调用）
- 嵌入模型：当前禁用（USE_LOCAL_EMBEDDING=false）
- 向量数据库：未启用
