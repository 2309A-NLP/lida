## 一、文档分析

### CN100342976C.pdf 基本信息
- 类型：中国发明专利说明书
- 发明名称：静电除尘器
- 页数：8页（6页文字+2页附图）
- 关键特征：**扫描型PDF（图片型），所有文字需要OCR提取**
- 第1页：专利著录信息（发明人、申请号等）
- 第2页：权利要求书
- 第3-6页：说明书正文
- 第7-8页：附图（管状入口和除尘器结构图）

- Q2（特征描述）：需要精确提取权利要求1的关键技术特征

- Q4（X1X2X3）：需要理解数学公式的上下文
- Q5（气流方向）：需要从附图和文字中推断气流方向
- Q6（h1h2）：需要理解尺寸参数的用途

## 二、优化策略

### 策略1：解析方法选择
- **推荐：DeepDOC**（默认）—— 扫描型PDF必须用OCR
- 备选：PaddleOCR（可能对中文更好）
- 不可用：PlainText（扫描PDF无文本层）

### 策略2：分块参数调优

```json
{
  "chunk_token_num": 512,
  "delimiter": "\n!?。；！？",
  "layout_recognize": "DeepDOC",
  "html4excel": false,
  "raptor": false,
  "graphrag": false,
  "table_context_size": 8,
  "image_context_size": 3
}
```

关键参数说明：
- `chunk_token_num: 512` — 较大块保留更多上下文（专利文档段落较长）
- `image_context_size: 3` — 图片前后保留3个chunk作为上下文（利于图文理解）
- `table_context_size: 8` — 表格前后保留更多上下文

### 策略3：检索参数调优

```json
{
  "similarity_threshold": 0.1,
  "vector_similarity_weight": 0.3,
  "top_k": 1024,
  "top_n": 8
}
```

关键参数：
- `similarity_threshold: 0.1` — 降低阈值（扫描OCR文本与query的匹配度可能偏低）
- `vector_similarity_weight: 0.3` — 向量权重30%，关键词权重70%（专利术语精确匹配更重要）

### 策略4：启用 Rerank
- 配置 Rerank 模型（如 BAAI/bge-reranker-v2-m3）
- Rerank 能在初筛后重新排序，显著提升精确匹配

### 策略5：针对图文混合问题的优化
对于Q3（部件位置）、Q5（气流方向）这类需要理解附图的问题：
- 启用 Vision LLM 描述图片
- 或手动在知识库中添加图片描述文本
- image_context_size 设为较大值

### 策略6：极端情况——代码修改
如果以上参数调优无法达到100%，可能需要：
1. 修改OCR后处理（修正专利号格式）
2. 修改分块逻辑（保证权利要求完整不被切断）
3. 添加自定义的专利文档解析器

## 三、调优步骤

### 第一轮：默认配置测试
1. 用默认参数创建知识库
2. 上传 CN100342976C.pdf
3. 选择 DeepDOC 解析
4. 测试6个问题，记录初始结果

### 第二轮：参数调优
1. 调整 chunk_token_num（128→256→512）
2. 调整 similarity_threshold（0.2→0.1→0.05）
3. 调整 vector_similarity_weight（0.3→0.5→0.7）
4. 每次调整后重新测试

### 第三轮：检索策略优化
1. 启用 Rerank
2. 调整 top_k 和 top_n
3. 测试混合检索 vs 纯向量检索

### 第四轮：深度优化
1. 如果仍有问题，修改解析代码
2. 添加图片描述
3. 自定义后处理规则

## 四、预期难点和应对

| 难点 | 应对方案 |
|------|---------|
| OCR不准（Q1发明人名字） | 调整OCR参数或后处理修正 |
| 图文理解（Q3、Q5） | image_context_size + Vision LLM |
| 公式理解（Q4） | 增大chunk保留公式上下文 |
| 跨页内容 | 增大chunk_token_num + overlap |
| 中文专利术语 | 关键词权重调高 + 降低阈值 |
