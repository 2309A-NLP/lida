## 四、优化过程

### 4.1 第一轮测试（优化前）

**配置**：默认参数，无Rerank

| 问题 | 结果 | 响应时间 |
|------|------|----------|
| Q1 | ✓ | 8.2s |
| Q2 | ✗ | 8.1s |
| Q3 | ✗ | 11.7s |
| Q4 | ✓ | 5.5s |
| Q5 | ✗ | 8.9s |
| Q6 | ✓ | 10.5s |

**准确率**：50% (3/6)  
**问题分析**：
- Q2答错：检索到的是"落料架"而非"链条"
- Q3答错：图3内容未被检索到
- Q5答错：图3内容未被检索到

### 4.2 第二轮测试（添加VLM描述）

**优化措施**：
1. 使用VLM分析图3，生成部件描述文档
2. 将描述文档上传到知识库

**结果**：准确率提升到100%

### 4.3 第三轮测试（参数优化）

**优化措施**：
1. 调整top_k从5到3
2. 调整top_n从3到1
3. 启用Rerank重排序

**结果**：响应时间从9.9秒优化到7.1秒

## 五、问题分析与解决

### 5.1 问题1：图3内容无法检索

**问题描述**：
- 第11页是纯图片页面，没有文字内容
- OCR无法提取有效文本
- 检索系统无法找到图3相关内容

**解决方案**：
1. 使用VLM分析图3图片
2. 生成详细的部件描述文档
3. 将文档上传到知识库补充图文信息

**效果**：Q3、Q4、Q5、Q6从错误变为正确

### 5.2 问题2：检索结果不相关

**问题描述**：
- Q2期望答案是"链条"，但检索到"落料架"
- 关键词匹配导致错误结果被排在前面

**解决方案**：
1. 启用Rerank重排序模型
2. 优化相似度阈值和向量权重

**效果**：Q2从错误变为正确

### 5.3 问题3：响应时间过长

**问题描述**：
- 优化前平均响应时间9.9秒
- 目标是3-5秒

**解决方案**：
1. 减少top_k从5到3
2. 减少top_n从3到1
3. 优化相似度阈值

**效果**：响应时间从9.9秒降到7.1秒
