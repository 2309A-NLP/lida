## 1. 简介

家庭记账本Agent是一款智能对话式记账工具，支持爸爸、妈妈、女儿三位家庭成员的消费支出与财政收入记录。通过自然语言对话即可完成记账、查询、删除等操作。

---

## 2. 启动方式

### 2.1 安装依赖

```bash
pip install -r requirements.txt
```

### 2.2 启动服务

```bash
cd scripts
python api.py
```

### 2.3 访问界面

浏览器打开 http://localhost:5000

## 3. 使用说明

### 3.1 开场白

进入系统后，Agent会自动发送欢迎语：

> 您好，欢迎使用咱们小家专属记账本！请按照"x年x月x日，谁做什么事收入/支出多少钱"的格式来输入。请告诉我你的账目需求吧~

### 3.2 记账

按照自然语言描述即可记账，系统会自动识别日期、成员、类别、金额等信息。

**示例**：

| 输入 | 系统行为 |
|------|----------|
| 今天女儿买了双登山鞋499元 | 识别为：女儿、购物、登山鞋、支出499元 |
| 7月5日妈妈收到报销1000元 | 识别为：妈妈、报销、报销、收入1000元 |
| 今天爸爸买书花了50元 | 识别为：爸爸、买书、书、支出50元 |

**确认流程**：系统解析信息后会弹出确认卡片，回复"确认"保存，回复"取消"放弃。

### 3.3 查询

**按月查看家庭明细**：
```
看下这个月家里花钱明细
```

**按成员查看**：
```
这个月女儿花了多少钱？
```

**按项目查询**：
```
我哪天买的三体
```

### 3.4 删除

```
删除女儿报旅游团的费用
```

系统会先展示匹配的记录，确认后才执行删除。

### 3.5 导出

```
导出本月记录
```

可将当月记录导出为CSV格式。

### 3.6 帮助

```
帮助
```

显示所有可用指令。

## 6. 完整性引导

如果输入信息不完整，系统会提示补充。例如输入"买了一双鞋"，系统会提示：

- 缺少：成员、日期、金额
- 请补充：是谁消费的？什么时候？花了多少钱？

---

## 7. 常见问题

**Q: 系统识别不了我的输入怎么办？**  
A: 尽量包含日期、成员、物品、金额四个要素，例如"今天妈妈买菜花了50元"。

**Q: 能修改已记录的账目吗？**  
A: 目前支持删除后重新录入，暂不支持直接修改。

**Q: 数据存储在哪里？**  
A: 所有数据存储在 `data/money_notes.db` SQLite数据库中。
