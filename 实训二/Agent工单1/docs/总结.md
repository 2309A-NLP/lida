# 📋 记账本Agent 项目总结

> 项目路径: `D:\Agent工单\Agent工单1`

---

## 一、项目简介

家庭记账本智能体，通过**自然语言对话**实现家庭账目管理。用户说出"今天女儿买了登山鞋499元"，系统就能自动识别意图、提取信息、存入数据库。

**工单编号**: 人工智能NLP-Agent数字人项目-记账本任务  
**版本**: V1.0  
**启动端口**: 5000

---

## 二、核心功能

| 功能 | 说明 | 示例 |
|------|------|------|
| **记 账** | 记录收支，支持多条一并录入 | 今天女儿买了登山鞋499元 |
| **查 询** | 按月/成员/项目/类别查询 | 这个月买书花了多钱 |
| **汇 总** | 统计收入/支出/净收入 | 看下这个月家里花钱明细 |
| **删 除** | 删除指定记录（确认后执行） | 删除登山鞋的费用 |
| **清 空** | 清空所有数据 | 清空所有记录 |
| **确认机制** | 增删改前确认，防误操作 | 回复"确认"或"取消" |

### 家庭成员
- 爸爸（别名：爸、父亲、老爸、爹）
- 妈妈（别名：妈、母亲、老妈、娘）
- 女儿（别名：闺女、孩子、小孩、丫头）

## 三、系统架构

```
用户 → Web终端界面 (index.html)
          ↓ HTTP POST /api/chat
      Flask API (api.py:5000)
          ↓
      Agent引擎 (agent.py)
          ↓ LLM API (MiMo-v2.5-pro)
      意图识别 → 结构化JSON
          ↓
      SQLite数据库 (database.py)
          ↓
      返回结果 → 呈现到终端
```

## 六、数据流

```
用户输入: "今天女儿买了双登山鞋499元"
    ↓
agent.py → call_llm() → MiMo API
    ↓
LLM返回JSON: {intent:"record", records:[{date:"2026-06-23", member:"女儿",
             category:"购物", item:"登山鞋", amount:499, type:"支出"}]}
    ↓
handle_record() → 显示确认卡片
    ↓
用户回复:"确认"
    ↓
confirm_record() → database.add_record() → SQLite存储
    ↓
返回: "✅ 已记录：2026-06-23，女儿，购物，登山鞋，支出499.0元"
```
