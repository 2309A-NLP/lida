## 一、Agent核心引擎 (agent.py)

### 1.1 LLM集成

**提供商**: MiMo (小米)  
**API端点**: `https://token-plan-cn.xiaomimimo.com/v1`  
**模型**: `mimo-v2.5-pro`（推理模型）  
**配置方式**: 环境变量 `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`

```python
from openai import OpenAI
client = OpenAI(base_url=LLM_BASE_URL, api_key=LLM_API_KEY)

response = client.chat.completions.create(
    model=LLM_MODEL,           # mimo-v2.5-pro
    messages=[...],
    temperature=0.1,           # 低温度，保证结构化输出一致性
    max_tokens=2000,           # 推理模型必须2000+，否则reasoning tokens吃光预算
)
```

**关键参数**:
- `temperature=0.1`: 结构化JSON输出需要低随机性
- `max_tokens=2000`: 推理模型的reasoning_tokens消耗量大，设太低会导致content返回空字符串
- `finish_reason == 'length'` 诊断：检查 `usage.completion_tokens_details.reasoning_tokens` 是否接近 max_tokens

### 1.2 系统提示词设计 (91行)

完整的 prompt engineering 包含：

**意图定义** (10种):
```json
{
  "intent": "record|query|query_member|query_item|query_category|delete|clear_all|help|chat",
  "records": [{...}],
  "missing": ["缺失字段"],
  "reply": "直接回复"
}
```

**多记录拆分规则**：
> "当用户一句话中包含多条记账信息时（用'又'、'随后'、'然后'、'还'、'接着'等连接），必须拆分成records数组中的多个元素"

**别名系统**：
- 爸爸 ← 爸、父亲、老爸、爹
- 妈妈 ← 妈、母亲、老妈、娘
- 女儿 ← 闺女、孩子、小孩、丫头

**类别自动推断规则**：
- 鞋 → 购物，书 → 买书，报销 → 报销，等等

### 1.3 意图处理流程

```python
def process_message(message: str) -> str:
    # 1. 确认/取消快捷处理
    if message.strip() in ["确认", "确认删除"]:
        return confirm_record() or confirm_delete()
    if message.strip() == "取消":
        return cancel_record()
    if message.strip() == "确认清空":
        return confirm_clear_all()

    # 2. LLM意图识别
    parsed = call_llm(message)

    # 3. 分发处理
    intent = parsed.get("intent", "chat")
    handlers = {
        "record": handle_record,
        "query": handle_query,
        "query_member": handle_query,
        "query_item": handle_query_item,
        "query_category": handle_query_category,
        "delete": handle_delete,
        "clear_all": handle_clear_all,
        "help": lambda p: OPENING_MESSAGE,
    }
    return handlers.get(intent, lambda p: p.get("reply", OPENING_MESSAGE))(parsed)
```

### 1.4 确认流程

| 操作 | 初次输入 | 确认 | 取消 |
|------|----------|------|------|
| 记账 | 显示确认卡片(日期/成员/类别/金额) | "确认" → 保存到DB | "取消" → 丢弃 |
| 删除 | 显示待删记录详情 | "确认删除" → 从DB删除 | "取消" → 丢弃 |
| 清空 | 显示记录总数+金额 | "确认清空" → DELETE FROM | "取消" → 丢弃 |

**缓存机制**: 全局字典 `pending_confirmations = {}` 存储待确认数据

### 1.5 多记录处理

- 单条记录 → 标准确认卡片
- 多条记录 → 编号列表: `【1】女儿，购物，登山鞋，支出499元`
- 支持复合句：`"爸爸今天买了奔驰300000，又买了衣服1000"` → 2条记录

## 三、数据库模块 (database.py)

### 3.1 表结构

```sql
CREATE TABLE money_notes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    date TEXT NOT NULL,               -- 日期 YYYY-MM-DD
    member TEXT NOT NULL,             -- 成员
    category TEXT NOT NULL,           -- 类别
    item TEXT NOT NULL,               -- 项目
    amount REAL NOT NULL,             -- 金额
    type TEXT NOT NULL CHECK(type IN ('收入', '支出')),  -- 收支类型
    note TEXT DEFAULT '',
    created_at TEXT DEFAULT (datetime('now', 'localtime')),
    updated_at TEXT DEFAULT (datetime('now', 'localtime'))
);

-- 索引
CREATE INDEX idx_date ON money_notes(date);
CREATE INDEX idx_member ON money_notes(member);
CREATE INDEX idx_category ON money_notes(category);
CREATE INDEX idx_type ON money_notes(type);
```

### 3.2 查询方法

| 方法 | 说明 | SQL特点 |
|------|------|---------|
| `add_record()` | 插入记录 | INSERT |
| `delete_record(id)` | 按ID删除 | DELETE WHERE id=? |
| `update_record(id, **kwargs)` | 动态更新 | 动态SET子句 |
| `query_by_date_range()` | 日期范围查 | BETWEEN |
| `query_by_member()` | 按成员查 | member=? |
| `query_by_category()` | 按类别查 | category=? |
| `query_by_item()` | 模糊查项目 | LIKE '%item%' |
| `get_summary()` | 汇总统计 | GROUP BY type + SUM |
| `get_member_summary()` | 成员汇总 | GROUP BY member, type |
| `get_category_summary()` | 类别汇总 | GROUP BY category, type |
| `clear_all_records()` | 清空全部 | DELETE + COUNT |

### 3.3 线程安全

```python
self.conn = sqlite3.connect(db_path, check_same_thread=False)
```

`check_same_thread=False` 允许在Flask多线程环境中跨线程使用同一个连接。

### 3.4 单例模式

```python
_db_instance = None
def get_db() -> MoneyDatabase:
    global _db_instance
    if _db_instance is None:
        _db_instance = MoneyDatabase()
    return _db_instance
```
