# 实现步骤与过程问题记录

## 1. 实现步骤

1. 阅读 PDF 工单，提炼刚性要求：
   - 输入单张人脸图
   - 输出左转、右转、端正三张图
   - 输出扩图结果
   - 提供测试结果和过程文档
2. 设计项目结构：
   - `src/config.py` 管理配置
   - `src/image_utils.py` 处理人脸裁切
   - `src/prompting.py` 统一生成三种姿态提示词
   - `src/pipeline.py` 封装百炼异步图像编辑工作流
   - `run.py` 提供命令行入口
   - `app.py` 提供 Web 演示入口
3. 实现图像预处理：
   - 使用 OpenCV 检测主人脸
   - 裁切到统一正方形区域
   - 缩放到统一推理分辨率
4. 实现三视角生成：
   - 基于百炼 `wanx2.1-imageedit`
   - 通过 `description_edit` 区分 `端正 / 左转 / 右转`
   - 通过随机种子提升复现性
5. 实现扩图：
   - 使用百炼 `expand`
   - 保持主体一致并补全外围区域
6. 实现交付配套：
   - 自动保存图片结果
   - 自动生成 `result_manifest.json`
   - 编写测试与文档

## 2. 过程问题记录

1. 问题：中文路径在部分终端显示有乱码
   - 影响：日志阅读不够直观
   - 处理：代码统一使用 `Path` 和 `utf-8` 写出结果文件
2. 问题：本机 CPU 推理无法满足高质量快速出图
   - 影响：本地 Stable Diffusion 路线生成时间过长且不稳定
   - 处理：切换为阿里云百炼在线图像编辑 API，避免本机算力瓶颈
3. 问题：在线图像编辑接口为异步任务
   - 影响：不能同步立即返回图像结果
   - 处理：代码中加入 `创建任务 -> 轮询任务 -> 下载结果` 流程
