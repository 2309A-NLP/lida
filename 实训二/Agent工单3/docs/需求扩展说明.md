# 需求扩展说明

## 1. 原始需求保留

根据 PDF 原始工单，完整保留以下要求：

1. 项目名称：Agent数字人项目文生图智能体任务
2. 任务目标：给定 1 张面部图像，生成左转、右转、端正三张图像，并且还需要扩图
3. 工时预估：2 人日
4. 产出物：
   - 功能实现代码
   - 测试结果
   - 实现步骤、过程问题记录文档或演示材料
5. 验收标准：
   - 输入原图后，生成三张满足要求的效果图
   - 面部特征保持一致，包括五官形状、眼睛颜色、肤色等
   - 面部不能出现扭曲、变形或模糊
   - 左转和右转应体现明显角度变化
   - 端正图应体现正面效果
   - 图像应保持清晰，不应像素化或失真
   - 扩图部分应与原图内容一致，不应出现无关元素
   - 扩图部分应自然融入原图，不应出现拼接痕迹
   - 扩图后的图像在清晰度、色彩还原度、对比度方面应有提升
6. 备注要求：
   - 使用 `Stable Diffusion` 或 `ComfyUI`
   - 代码注释需包含工单编号

## 2. 在原始需求基础上的补充说明

为了保证项目可实现、可验收、可交付，在不减少原始需求的前提下补充以下内容：

1. 输入建议：
   - 建议输入为单人正脸或近正脸图片
   - 建议分辨率不低于 `512x512`
   - 建议五官无遮挡
2. 技术方案：
   - 当前采用阿里云百炼在线图像编辑 API 实现
   - 先做人脸检测与居中裁切，再执行姿态生成
   - 姿态生成通过 `description_edit` 完成
   - 扩图通过 `expand` 完成
3. 推理流程：
   - `原图预处理` -> `端正图生成` -> `左转图生成` -> `右转图生成` -> `扩图生成`
4. 工程交付：
   - 提供 `CLI` 与 `Web UI`
   - 自动保存图片结果和结果清单
   - 提供基础测试与文档
