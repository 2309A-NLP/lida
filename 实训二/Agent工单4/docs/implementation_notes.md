## 3. 当前问题记录

- 外部数据集中的 SQLite 数据库文件在常规下载方式下存在中文文件名编码兼容问题

- 已通过 git blob 直接导出的方式绕开该问题，当前主阻塞已解除

## 4. 解决策略

- 保留完整项目代码和统一配置，确保数据库文件落位后无需改代码即可运行
- 对结构化问答链路使用“可执行 SQL 引擎 + 可扩展 SQL 规划器”的主流实现方式
- 对招股书类题目先用 TF-IDF 文本检索完成最小可用能力
- 在文档中明确记录外部数据接入过程，避免遗漏 PDF 要求中的任何交付项
