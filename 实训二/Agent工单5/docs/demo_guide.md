# 演示说明文档

## 工单编号

`人工智能NLP-Agent数字人项目-招股书数据问答智能体任务`

## 功能演示

### 1. Web界面演示

本项目提供了一个完整的Web工作台界面，用于演示招股书问答功能。

#### 启动步骤

1. **安装依赖**
```bash
pip install -r requirements.txt
```

2. **下载知识库数据**
```bash
python scripts/download_knowledge_base.py
```

3. **构建索引**
```bash
python scripts/build_index.py
```

4. **启动Web服务**
```bash
python scripts/run_web.py
```

5. **访问界面**
打开浏览器访问：http://127.0.0.1:8001

### 2. 界面功能说明

#### 2.1 首页展示
- **品牌区域**：展示项目名称和功能介绍
- **统计信息**：显示RAG、SQL、FAST三大核心能力
- **示例问题**：提供4个预设问题快速测试
- **知识库信息**：显示当前加载的数据集信息

#### 2.2 问答区域
- **问题输入框**：输入或点击示例问题
- **提交按钮**：发送问题到后端
- **清空按钮**：清空输入和输出
- **进度条**：显示请求处理状态

#### 2.3 结果展示
- **答案区域**：显示AI生成的答案
- **证据区域**：显示前两条检索到的证据摘要
- **元信息区域**：
  - 路由类型（prospectus/unsupported）
  - 置信度
  - 响应耗时（ms）
  - 证据数量

### 5. CLI批量问答演示

#### 5.1 运行批量问答
```bash
python scripts/answer_questions.py --limit 10
```

**说明**：
- 读取 `dataset_raw/question.json` 中的问题
- 使用 `--limit` 限制处理数量（不指定则处理全部1000题）
- 输出到 `outputs/answers.jsonl`
- 同时输出带证据的详细版本到 `outputs/answers_with_evidence.jsonl`

```bash

```

**输出格式**：
```jsonl
{"id": 0, "question": "...", "answer": "..."}
{"id": 1, "question": "...", "answer": "..."}
```

### 8. 常见问题

**Q: 为什么有些问题返回"不支持"？**
A: 数据集中混合了招股书问题和数据库统计问题。数据库类问题需要SQL查询支持，当前版本已完整实现招股书RAG主链路，数据库题会被路由并说明原因。

**Q: 如何判断答案质量？**
A: 查看返回的置信度（confidence）和证据（evidence）。高置信度且证据相关的答案质量较高。

**Q: 能处理多少题？**
A: 系统可以处理全部1000题，使用 `--limit` 参数可控制处理数量进行快速测试。

**Q: 响应速度如何？**
A: 首次查询需要加载模型（~2-3秒），后续查询通常在100-300ms内完成。可查看返回的 `elapsed_ms` 字段。
