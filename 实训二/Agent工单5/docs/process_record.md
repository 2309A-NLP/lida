# 实现步骤与过程问题记录

## 工单编号

`人工智能NLP-Agent数字人项目-招股书数据问答智能体任务`

## 1. 需求理解

根据 `requirements.pdf`，本次实现至少需要覆盖：

- 基于招股书数据完成问答
- 使用主流 RAG 方案
- 自动使用提供的数据源构建知识库
- 根据题目文件补全 `answer` 字段
- 输出 `jsonl` 提交文件
- 交付实现代码与过程记录

## 2. 数据源确认

按照需求文档，尝试使用 `git lfs clone` 拉取数据集，但由于远端传输中断，多次失败。

后续改为使用 ModelScope Python SDK 与公开文件接口获取数据集元数据，确认：

- 题目文件实际名为 `question.json`
- 招股书文本文件清单位于 `pdf_txt_file.csv`
- 招股书文本位于 `pdf_txt_file/*.txt`
- 数据集同时包含 `博金杯比赛数据.db`
- 已成功补齐 80 份招股书文本

## 3. 发现的问题

### 3.1 PDF 与真实数据集命名不完全一致

- 需求 PDF 中写的是 `question.jsonl`
- 实际数据集提供的是逐行 JSON 格式的 `question.json`

处理方式：

- 代码按真实文件名读取
- 输出结果仍然按验收要求导出为 `jsonl`

### 3.2 数据集存在混合题型

题库并不全是招股书问题，还混入了基金、股票、行业、净值等数据库统计题。

处理方式：

- 当前版本完整实现招股书问答主链路
- 对非招股书题进行路由识别并返回说明
- 代码结构上预留数据库题扩展能力

### 3.3 数据库大文件公开直链返回 404

SDK 可枚举到 `dataset/博金杯比赛数据.db`，但通过公开下载接口获取时返回 `404`。

处理方式：

- 不阻塞招股书主线交付
- 在文档中记录该问题
- 后续如有可用下载凭证或镜像，可补接数据库问答模块

## 4. 实现方案

采用本地 RAG 主链路：

1. 自动拉取题目文件、元数据和招股书文本
2. 对招股书文本执行清洗和切块
3. 构建 BM25 + TF-IDF 混合检索器
4. 对题目进行题型路由
5. 对招股书类问题执行检索与证据抽取
6. 输出答案与证据文件
7. 提供 CLI 与 API

当前索引构建结果：

- 招股书文本文件：80 份
- 文本切片：24,844 个
- 题库总量：1000 题
- 已导出全量答案文件：`outputs/answers.jsonl`
