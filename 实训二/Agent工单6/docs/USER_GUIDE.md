## 系统概述

智能体任务工单系统是一个基于AI的智能工单管理平台，提供以下核心功能：

- 🤖 **智能对话**: 通过自然语言与AI助手交流，自动创建和管理工单
- 📋 **工单管理**: 完整的工单生命周期管理（创建、跟踪、处理、完成）
- 🧠 **NLP分析**: 自动分析工单内容，识别意图和情感
- 🚀 **自动化处理**: 智能Agent自动分配和处理工单
- 📊 **数据统计**: 实时统计和分析工单数据

## 快速开始

### 1. 访问系统

打开浏览器，访问: `http://localhost:8000`

### 2. 创建第一个工单

**方法一：通过智能对话**
1. 在左侧聊天区域输入您的问题或需求
2. 例如："我的系统无法登录，提示密码错误"
3. AI助手会自动理解并为您创建工单
4. 工单会显示在右侧工单列表中

**方法二：通过API**
```bash
curl -X POST http://localhost:8000/api/workorders \
  -H "Content-Type: application/json" \
  -d '{
    "title": "系统登录问题",
    "description": "无法登录系统",
    "category": "技术支持",
    "priority": "高",
    "creator_name": "张三"
  }'
```

### 3. 查看工单

- 在右侧工单列表中点击任意工单查看详情
- 可以看到工单的完整信息、处理进度和消息记录

## 功能说明

### 智能对话

**功能描述**:
- 使用自然语言描述问题
- AI自动识别意图和情感
- 自动创建合适的工单类型
- 支持持续对话和跟进

**使用技巧**:
- 详细描述问题，包含关键信息
- 可以在对话中补充联系方式
- AI会根据内容自动判断优先级

**示例对话**:
```
用户: 数据库连接失败，影响业务运行
AI: 我理解这是一个紧急的技术问题。我已为您创建工单（编号：WO202506250001），
    并标记为"紧急"优先级，技术团队将立即处理。
```

### 工单管理

#### 工单状态
- **待处理**: 新创建的工单，等待分配
- **处理中**: 已分配给团队，正在处理
- **已完成**: 问题已解决，工单关闭
- **已取消**: 工单被取消
- **待审核**: 需要进一步审核

#### 工单类别
- **技术支持**: 技术问题咨询
- **业务咨询**: 业务流程相关
- **故障报修**: 系统故障报修
- **需求开发**: 新功能需求
- **其他**: 其他类型问题

#### 优先级
- **紧急**: 影响核心业务，需立即处理
- **高**: 重要问题，优先处理
- **中**: 正常问题，按序处理
- **低**: 非紧急问题

### 筛选和搜索

**按状态筛选**:
在工单列表上方选择状态筛选器，快速查看特定状态的工单。

**按类别筛选**:
选择类别筛选器，查看特定类型的工单。

**组合筛选**:
可以同时使用状态和类别筛选器。

### 统计数据

在工单列表上方显示实时统计信息：
- **总工单**: 系统中所有工单数量
- **待处理**: 等待处理的工单数
- **处理中**: 正在处理的工单数
- **已完成**: 已完成的工单数

## 常见问题

### Q1: 如何创建紧急工单？
**A**: 在描述中使用"紧急"、"urgent"等关键词，系统会自动识别并提高优先级。

### Q2: 工单创建后可以修改吗？
**A**: 可以通过API更新工单信息，包括状态、优先级、负责人等。

### Q3: 如何查看工单处理进度？
**A**: 点击工单查看详情，可以看到完整的消息记录和操作日志。

### Q4: 支持批量操作吗？
**A**: 当前版本通过API支持批量查询，后续版本将增加更多批量操作功能。

### Q5: 数据如何备份？
**A**: 数据存储在 `data/workorders.db`，定期备份该文件即可。

### Q6: 可以集成到现有系统吗？
**A**: 可以，系统提供完整的REST API，支持与其他系统集成。详见API文档。

### Q7: 支持多语言吗？
**A**: 当前版本主要支持中文，可通过配置文件调整NLP语言设置。

### Q8: 如何自定义工单类别？
**A**: 修改 `config/config.yaml` 中的 `workorder.categories` 配置。

### Q9: 系统支持多少并发用户？
**A**: 取决于部署环境。单机模式建议不超过100并发，生产环境建议使用PostgreSQL和负载均衡。

### Q10: 如何升级系统？
**A**: 备份数据库后，更新代码并重启服务。数据库结构会自动升级。

## 进阶使用

### 自定义AI提示词
修改 `backend/services.py` 中的响应生成逻辑，自定义AI助手的行为。

### 集成外部AI服务
在 `.env` 中配置OpenAI或Anthropic API密钥，启用高级NLP功能。

### 添加自定义字段
1. 修改 `models/database.py` 添加数据库字段
2. 更新 `models/schemas.py` 添加API schema
3. 更新前端显示逻辑

### Webhook集成
配置 `config/config.yaml` 中的 `notification.webhook`，实现工单事件通知。
