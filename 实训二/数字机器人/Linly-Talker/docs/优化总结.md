## 一、显存与内存优化

### 1.1 按需加载LLM模型
- **优化前**: WebUI 启动时加载所有模型，显存占用巨大
- **优化后**: 默认不加载 LLM 模型，仅在用户选择对应模型时按需加载
- **效果**: 大幅降低启动显存占用

### 1.2 显存清理机制
**代码位置**: `webui.py` → `clear_memory()` 函数

```python
def clear_memory():
    gc.collect()                       # 触发Python垃圾回收
    torch.cuda.empty_cache()           # 清理PyTorch显存缓存
    torch.cuda.ipc_collect()           # 清理跨进程通信缓存
```

每次对话完成后自动调用，防止显存泄漏。

### 1.3 显存使用监控

```python
print(f"Memory allocated: {torch.cuda.memory_allocated() / (1024**2):.2f} MB")
print(f"Max memory allocated: {torch.cuda.max_memory_allocated() / (1024**2):.2f} MB")
```

### 1.4 轻量版设计 (legal_app.py)
- 纯 Python HTTP Server，**无需 GPU**
- 使用 TF-IDF + jieba 本地检索，无模型加载开销
- 适合低配机器和纯文本咨询场景

## 二、法律检索优化

### 2.1 TF-IDF + jieba 分词检索

```
文本 → jieba精确模式分词 → TF-IDF向量化 → 余弦相似度排序
```

- **分词优化**: 过滤单字词和空白词，保留有意义的法律术语
- **特征数限制**: `max_features=10000`，控制索引大小
- **L2归一化**: `norm='l2'`，保证相似度分数可比

### 2.2 条款智能分割
**代码位置**: `LegalRAG.py` → `_split_articles()`

```python
pattern = r'(第[一二三四五六七八九十百零\d]+条[　 ]*.*?)(?=第[一二三四五六七八九十百零\d]+条|\Z)'
```

- 支持中英文数字条款编号
- 过滤短文本（< 10字符跳过）
- 无「第X条」格式时按段落分割

### 2.3 检索去重
- 同一法律同一法条只展示一次
- 仅返回有相关性的结果（`scores[idx] > 0`）
- Top-K 默认为5条，最终展示前3条

## 三、推理与响应优化

### 3.1 耗时统计装饰器
**代码位置**: `src/cost_time.py`

```python
@calculate_time
def Asr(audio):
    ...
```

自动记录各模块处理时间，便于性能分析。

### 3.2 双模式LLM
| 模式 | 场景 | 说明 |
|------|------|------|
| **API模式** | 有网络 | 调用远程API（ChatGPT/Gemini等），速度快 |
| **Offline模式** | 无网络 | 本地推理，适合隐私场景 |

### 3.3 兜底回答机制
当 LLM 不可用时，`LegalRAG._fallback_answer()` 直接返回结构化的法条检索结果：
```

根据检索到的相关法律条文...

1. 《民法典》第XXXX条
   > 法条内容...

⚠️ 温馨提示：咨询专业律师或拨打 12348
```

## 四、多模型冗余设计

每个模块提供多种实现，用户按需选择：

| 模块 | 可选方案 | 选择依据 |
|------|----------|----------|
| **ASR** | Whisper / FunASR / OmniSenseVoice | 精度 vs 速度 |
| **TTS** | EdgeTTS / PaddleTTS / CosyVoice / GPT-SoVITS | 在线 vs 离线 vs 克隆 |
| **LLM** | 8种模型 | 本地 vs API, 精度 vs 资源 |
| **数字人** | SadTalker / Wav2Lip / MuseTalk / ER-NeRF | 质量 vs 实时性 |

## 五、知识库维护优化

### 5.1 热加载
LegalRAG 每次启动时重新加载知识库文件，支持动态更新：
- 在 `legal_kb/` 目录增加/修改 .txt 文件
- 重启服务即可生效

### 5.2 自动目录创建
```python
if not os.path.exists(self.kb_dir):
    os.makedirs(self.kb_dir, exist_ok=True)
```

### 5.3 多编码支持
```python
try:
    content = open(fpath, 'r', encoding='utf-8').read()
except UnicodeDecodeError:
    content = open(fpath, 'r', encoding='gbk').read()
```
