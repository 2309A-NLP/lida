## 一、系统架构总览

法小助·Linly-Talker 是一套基于 **Linly-Talker 数字人框架** 改造的法律数字人咨询系统，采用 **前端+后端+AI引擎** 三层架构。

```
┌─────────────────────────────────────────────────────┐
│                    前端层 (UI)                        │
│  ├─ legal_app.py 独立HTTP服务(高级前端,端口7860)      │
│  └─ webui.py Gradio WebUI(含数字人形象,端口6006)     │
├─────────────────────────────────────────────────────┤
│                     后端层                            │
│  ├─ LegalRAG 法律知识检索引擎 (TF-IDF + jieba)        │
│  ├─ ASR 语音识别模块 (Whisper / FunASR / OmniSense)  │
│  ├─ LLM 对话引擎 (8种模型)                            │
│  └─ API 服务层 (FastAPI)                              │
├─────────────────────────────────────────────────────┤
│                  数字人生成层 (THG)                    │
│  ├─ SadTalker (音频→数字人视频)                       │
│  ├─ Wav2Lip / Wav2Lipv2 (唇形同步)                    │
│  ├─ MuseTalk (实时数字人对话)                          │
│  ├─ ER-NeRF (NeRF数字人)                              │
│  └─ MuseV (视频生成)                                  │
├─────────────────────────────────────────────────────┤
│                    TTS语音合成层                       │
│  ├─ EdgeTTS (微软,在线)                               │
│  ├─ PaddleTTS (百度,离线)                             │
│  ├─ CosyVoice (语音克隆)                              │
│  └─ GPT-SoVITS (语音克隆,微调)                        │
└─────────────────────────────────────────────────────┘
```

## 二、核心模块设计

### 2.1 法律RAG引擎 (LegalRAG)

**文件**: `LLM/LegalRAG.py`

基于 TF-IDF + jieba 分词的法律知识检索增强生成模块，完全兼容原 LLM 接口。

```
用户问题 → jieba分词 → TF-IDF向量化 → 余弦相似度检索
→ 检索Top-K法条 → 构建增强Prompt → LLM生成回答
                         ↓
                  无LLM时: 结构化的兜底回答
```

**设计要点**:
- `LegalRetriever`: 法律条文检索器，按「第X条」格式自动分割条款
- `LegalRAG`: 主类，封装检索+生成，兼容 `generate(question)` 接口
- `_fallback_answer`: LLM不可用时的兜底模式，直接展示检索到的法条
- 支持 `OPENAI_API_KEY` 环境变量配置，自动初始化 ChatGPT 作为底层 LLM

### 2.2 LLM 对话引擎

**文件**: `LLM/__init__.py`, `LLM/template.py`

工厂模式设计，统一初始化接口：

| 模型 | 模式 | 说明 |
|------|------|------|
| Linly | offline/api | 国产中文LLM |
| Qwen / Qwen2 | offline/api | 通义千问系列 |
| Gemini | api | Google Gemini Pro |
| ChatGPT | api | OpenAI GPT系列 |
| ChatGLM | offline | 清华GLM系列 |
| Llama2Chinese | offline | 中文LLaMA |
| GPT4Free | api | 免费GPT接口 |
| QAnything | api | 网易有道RAG |
| **LegalRAG** | **offline** | **法律RAG(本项目核心)** |

**统一接口**: 所有LLM通过 `generate(prompt)` 返回回答，通过 `LLM.init_model(name)` 工厂方法创建。

## 三、Web前端设计

### 3.1 轻量版前端 (legal_app.py)
- **端口**: 7860
- **技术**: Python HTTP Server + 内嵌HTML/CSS/JS
- **风格**: 暗色科技风，左侧对话面板 + 右侧侧边栏
- **功能**: 对话、法条展示、快捷提问、系统状态
- **无需GPU**: 纯文本法律咨询

### 3.2 完整版前端 (webui.py)
- **端口**: 6006
- **技术**: Gradio 4.16.0
- **功能**: 语音输入、数字人形象、多模型切换、语音克隆
- **需要GPU**: 数字人生成和部分LLM需要
