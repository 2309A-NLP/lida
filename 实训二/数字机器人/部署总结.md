## 一、部署方式总览

| 部署方式 | 适用场景 | 需要GPU | 端口 |
|----------|----------|---------|------|
| **轻量版 (legal_app.py)** | 纯文本法律咨询，低配机器 | ❌ 否 | 7860 |

## 二、轻量版部署 (推荐快速体验)

### 2.1 前置要求
- Python 3.8+
- 无需GPU
- 建议配置 `OPENAI_API_KEY` 以获得更好回答质量

### 2.2 启动命令

```bash
cd D:\数字机器人\Linly-Talker

# 有API Key（推荐）
set OPENAI_API_KEY=sk-xxxxxx
python legal_app.py

# 无API Key（使用内置知识库兜底）
python legal_app.py
```

### 2.3 访问
浏览器打开 `http://localhost:7860`

### 2.4 依赖
无需额外安装依赖，Python标准库 + 自动导入的LLM模块即可运行。

## 三、完整版部署 (含数字人)

### 3.1 硬件要求
- **GPU**: NVIDIA GPU 12GB+ 显存（推荐24GB）
- **内存**: 16GB+
- **硬盘**: 50GB+（存放模型文件）

### 3.2 环境安装

```bash
cd D:\数字机器人\Linly-Talker

# 安装依赖
pip install -r requirements_app.txt       # 轻量版依赖
pip install -r requirements_webui.txt     # 完整版依赖（含PyTorch）

# 安装 MuseTalk 额外依赖（如需实时数字人）
pip install --no-cache-dir -U openmim
mim install mmengine
mim install "mmcv>=2.0.1"
mim install "mmdet>=3.1.0"
mim install "mmpose>=1.1.0"
```

### 3.3 下载模型

```bash
# 方式1: ModelScope（推荐，国内快）
pip install modelscope
sh scripts/download_models.sh
# 选择 [1] ModelScope

# 方式2: HuggingFace
sh scripts/download_models.sh
# 选择 [2] HuggingFace

# 方式3: HuggingFace镜像
sh scripts/download_models.sh
# 选择 [3] HF镜像
```

### 3.4 启动

```bash
python webui.py
```

访问 `http://localhost:6006`

## 四、AutoDL云端部署

### 4.1 创建实例
1. 注册 [AutoDL](https://www.autodl.com)
2. 进入算力市场，选择 GPU 实例（推荐 RTX 3090 / 4090）
3. 选择基础镜像（PyTorch 2.0+）
4. 先用**无卡模式**开机（0.1元/小时）安装环境

### 4.2 安装环境

```bash
source /etc/network_turbo

cd /root/autodl-tmp/
git clone https://github.com/Kedreamix/Linly-Talker.git --depth 1
cd Linly-Talker

unset http_proxy && unset https_proxy

# 安装依赖
pip install tb-nightly -i https://mirrors.aliyun.com/pypi/simple
pip install -r requirements_webui.txt

# 下载模型
pip install modelscope -i https://pypi.tuna.tsinghua.edu.cn/simple
sh scripts/download_models.sh
```

### 4.3 有卡开机
1. 关闭实例 → 切换为有卡模式 → 开机
2. 验证 GPU：`nvidia-smi`
3. 启动：`python webui.py`
4. 在 AutoDL 控制台配置自定义服务，端口 **6006**

### 4.4 注意事项
- ⏰ **用完后务必关机**，按时收费
- 建议选择北京区，GPU 更充足

## 五、API服务部署

### 5.1 LLM API

```bash
# 启动LLM API
cd D:\数字机器人\Linly-Talker\api
python llm_api.py
# 端口: 7871
```

### 5.2 数字人API

```bash
python api/talker_api.py
```

### 5.3 TTS API

```bash
python api/tts_api.py
```

### 5.4 客户端调用示例

```python
from api.llm_client import LLMClient
from api.talker_client import TalkerClient
from api.tts_client import TTSClient

# LLM对话
llm = LLMClient(host='localhost', port=7871)
answer = llm.generate("离婚财产怎么分割？")

# TTS语音合成
tts = TTSClient(host='localhost', port=7872)
tts.synthesize("法小助为您解答", voice="zh-CN-XiaoxiaoNeural")

# 数字人生成
talker = TalkerClient(host='localhost', port=7873)
talker.generate("image.jpg", "answer.wav")
```

## 九、故障排查

### 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 端口被占用 | 端口冲突 | 修改 `configs.py` 中的 `port` |
| 模型下载失败 | 网络问题 | 使用 ModelScope 或镜像源 |
| 显存不足 | GPU内存不够 | 使用轻量版或降低模型大小 |
| ASR报错 | 音频未传入 | 重新点击语音识别按钮 |
| API Key错误 | Key无效 | 检查 `OPENAI_API_KEY` |
