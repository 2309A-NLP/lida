# 压力测试指南

## 1. 概述

本指南说明如何对 RAG 多角色智能聊天机器人进行性能压力测试，包括测试脚本的使用方法、性能指标解读、以及系统瓶颈定位。

## 2. 测试脚本清单

项目 tests/ 目录下提供三个压力测试脚本：

| 脚本 | 引擎 | 适用场景 | 并发能力 |
|---|---|---|---|
| qps_light_test.py | Python requests + ThreadPool | 快速基准测试（3并发） | 轻量，1/5/10 并发 |
| qps_stress_test.py | Python requests + ThreadPool | 完整性能评估 | 递增，1/5/10/20 并发 |
| qps_test.py | Locust | 持续负载测试 + Web监控 | 可配置任意并发 |

## 3. 环境准备

### 3.1 启动服务
```bash
cd /mnt/d/RAG_多角色智能聊天机器人项目
python main.py --host 0.0.0.0 --port 8080
```

### 3.2 确认服务可用
```bash
curl http://127.0.0.1:8080/roles
```
返回 200 且包含角色列表数据即可。

### 3.3 依赖安装
```bash
# 轻量/完整压力测试（Python脚本）
pip install requests

# Locust 压力测试
pip install locust
```

| 场景 | 端点 | 单次请求量级 | 并发策略 |

### 4.4 指标解释
- **QPS** (Queries Per Second)：每秒处理的请求数，越高代表吞吐能力越强
- **平均**：所有请求的平均延迟（毫秒）
- **P50**：50%的请求在此延迟以下（中位数）
- **P90**：90%的请求在此延迟以下（典型峰值）
- **P99**：99%的请求在此延迟以下（极端情况）
- **错误**：失败的请求数（非200状态码或超时）

## 6. Locust 压力测试 (qps_test.py)

### 6.1 运行方式
```bash
cd tests
locust -f qps_test.py --host=http://localhost:8080
```

### 6.2 访问 Web 界面
打开浏览器访问 http://localhost:8089

### 6.3 配置参数
| 参数 | 推荐值 | 说明 |
|---|---|---|
| Number of users | 10-50 | 模拟的并发用户总数 |
| Spawn rate | 5-10 | 每秒新增的用户数 |
| Host | http://localhost:8080 | 目标服务器地址 |

### 6.4 测试场景权重
| 任务 | 权重 | 说明 |
|---|---|---|
| send_message | 5 | 发送聊天消息（最频繁） |
| get_roles | 2 | 获取角色列表 |
| get_history | 2 | 获取聊天历史 |
| search_knowledge | 1 | 搜索知识库 |
| register_user | 1 | 用户注册（初始化） |
| login_user | 1 | 用户登录 |

### 6.5 Locust 报告解读
- **# Requests**：总请求数
- **Fails**：失败请求数和失败率
- **Median (ms)**：P50 延迟
- **90%ile (ms)**：P90 延迟
- **Average (ms)**：平均延迟
- **Min/Max**：最小/最大延迟
- **Average size (bytes)**：平均响应大小
- **Current RPS**：当前每秒请求数
- **Current Failure Rate**：当前失败率

## 7. 瓶颈分析与优化建议

### 7.1 典型瓶颈
| 瓶颈类型 | 症状 | 建议 |
|---|---|---|
| CPU 瓶颈 | 延迟随并发线性上升 | 增加 CPU 核数，优化计算逻辑 |
| 内存瓶颈 | OOM 或 Swap 使用 | 增加内存，减少每个请求的内存占用 |
| AI 模型推理慢 | POST /chat QPS 极低 | 使用流式输出、模型量化、GPU加速 |
| 向量检索慢 | knowledge/search QPS 低 | 添加索引、使用 Milvus 集群、减少 top_k |
| 数据库锁竞争 | 认证接口延迟高 | 使用连接池、读写分离 |
| 网络带宽 | 响应体大时延迟升高 | 启用压缩、CDN |

### 7.2 调优策略（按优先级）

1. **AI 模型层优化**：切换到更快的模型或 API，启用流式输出，调整 max_tokens
2. **向量检索优化**：增加 Milvus 索引（IVF_FLAT -> HNSW），使用 GPU 版 Milvus
3. **连接池调优**：增加 Redis 连接池大小，启用 HTTP Keep-Alive
4. **水平扩展**：用 Nginx 做负载均衡，多实例部署
5. **缓存层**：热点知识结果缓存到 Redis，减少重复向量检索

## 8. 常见问题

### Q: 服务返回 Connection refused
A: 确认服务已启动 `python main.py --port 8080`，检查端口是否被占用。

### Q: 测试脚本报错 ModuleNotFoundError
A: 进入项目根目录运行脚本，或设置 PYTHONPATH：
```bash
PYTHONPATH=/mnt/d/RAG_多角色智能聊天机器人项目 python tests/qps_light_test.py
```

### Q: POST /chat 超时（timeout=30）
A: 如果使用本地模型，首次加载可能较慢。可增加 timeout 参数值，或预热模型：
```python
requests.post(f"{BASE}/chat", json={...}, timeout=120)
```

### Q: 知识库检索返回空结果
A: 确认知识库文件已加载（运行 `POST /knowledge/reload`），检查 text_data/ 目录下的 .txt 文件。

### Q: Locust 启动报错 "module 'locust' has no attribute 'HttpUser'"
A: 升级 Locust 到最新版本：`pip install -U locust`
