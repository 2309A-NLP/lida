# RAG 质量评估

## 1. 概述

本系统基于 RAG（检索增强生成）技术实现智能聊天功能。质量评估分为两个维度：
- **检索质量**：知识库能否检索到与用户问题相关的专业知识
- **生成质量**：AI模型能否基于检索结果生成准确、相关、专业的回答

项目 tests/ 目录下提供了两种评估方法：自动化评估（RAGAS）和手动评估（文本相似度）。

## 2. 现有评估脚本

| 脚本 | 方法 | 依赖 | 评估指标 |
|---|---|---|---|
| ragas_eval.py | RAGAS 框架 | ragas, datasets, openai | Faithfulness, Context Precision |
| rag_manual_eval.py | 文本相似度 + 关键词召回 | requests, difflib | 检索相似度、答案相似度、关键词召回率 |

## 3. RAGAS 自动化评估 (ragas_eval.py)

### 3.1 原理

RAGAS 是一个开源 RAG 评估框架，通过调用 LLM 作为评判来评估 RAG 系统的输出质量。

### 3.2 安装依赖
```bash
pip install ragas datasets openai
```

### 3.3 运行方式
```bash
cd tests
python ragas_eval.py
```

### 3.4 评估指标

#### Faithfulness（忠实度）
- **含义**：AI 的回答是否忠实于检索到的知识上下文，不自作主张
- **范围**：0.0 - 1.0（越高越好）
- **优秀**：> 0.8
- **可接受**：0.5 - 0.8
- **需改进**：< 0.5
- **理想值**：0.85+

#### Context Precision（上下文精确度）
- **含义**：检索到的上下文中，与回答相关的信息占比
- **范围**：0.0 - 1.0（越高越好）
- **优秀**：> 0.7
- **可接受**：0.4 - 0.7
- **需改进**：< 0.4
- **理想值**：0.75+

### 3.7 注意事项
- RAGAS 使用 DeepSeek API 作为评估 LLM（兼容 OpenAI 接口）
- 需要正确配置 .env 文件中的 MODEL_API_KEY
- Answer Relevancy 和 Context Recall 由于需要 embedding API（DeepSeek 不支持），暂未启用
- 评估结果受评判 LLM 质量影响

## 4. 手动评估 (rag_manual_eval.py)

### 4.1 原理

不依赖外部 LLM 评判，使用文本相似度（SequenceMatcher）和关键词召回率直接评估 RAG 系统质量。

### 4.2 运行方式
```bash
cd tests
python rag_manual_eval.py
```

### 4.3 评估指标

#### 检索相似度 (Retrieval Score)
- **计算方式**：知识库检索到的上下文内容与参考答案的文本相似度
- **范围**：0.0 - 1.0
- **优秀**：> 0.30
- **一般**：0.15 - 0.30
- **需改进**：< 0.15

#### 答案相似度 (Answer Score)
- **计算方式**：AI 回答与参考答案的文本相似度
- **范围**：0.0 - 1.0
- **优秀**：> 0.15
- **一般**：0.08 - 0.15
- **需改进**：< 0.08

#### 关键词召回率 (Keyword Recall)
- **计算方式**：预设关键词在 AI回答/检索结果中的出现比例
- **范围**：0% - 100%
- **优秀**：> 60%
- **一般**：30% - 60%
- **需改进**：< 30%

## 6. 质量改进建议

### 6.1 检索质量提升
- 增加知识库条目数量和质量（更多专业的医学文献数据）
- 优化文本分段逻辑（按语义段落而非简单空行分割）
- 调整混合检索权重（hybrid_search_weight 参数）
- 增加 rerank_top_n 提升排序质量
- 使用更好的嵌入模型（如 BGE-M3 微调版）

### 6.2 生成质量提升
- 优化 System Prompt，更严格约束AI使用知识库内容
- 调整 LLM 参数：降低 temperature（建议 0.3-0.5），减少幻觉
- 增加检索到的上下文数量（top_k 和 rerank_top_n）
- 升级 LLM 模型（如 DeepSeek V3 等更强模型）

### 6.3 测试数据集完善
- 增加更多领域的测试用例（目前仅覆盖心理/精神科）
- 增加负面测试（AI应拒绝回答的问题）
- 增加多轮对话的上下文连续性测试

## 8. 质量验收标准

| 指标 | 最低要求 | 目标值 | 卓越值 |
|---|---|---|---|
| Faithfulness | > 0.60 | > 0.80 | > 0.90 |
| Context Precision | > 0.40 | > 0.70 | > 0.85 |
| 检索相似度 | > 0.15 | > 0.30 | > 0.50 |
| 答案相似度 | > 0.08 | > 0.15 | > 0.25 |
| 答案关键词召回 | > 30% | > 60% | > 80% |
| 检索关键词召回 | > 50% | > 80% | > 90% |
| 平均响应时间 (AI聊天) | < 10s | < 5s | < 2s |

未达到最低要求的模块需要制定改进计划并重新评估。
