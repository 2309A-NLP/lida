# 环境搭建指南

## 1. 系统要求

- Python 3.10+（推荐 3.12）
- Redis 7.0+（可选，不配置会自动降级到内存存储）
- MySQL 8.0+（可选，不配置会自动降级到内存存储）
- Milvus 2.3+（可选，不配置会自动降级到内存检索）
- Docker / Docker Compose（可选，用于容器化部署）

## 2. 创建 Python 虚拟环境

在项目根目录执行：

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python3 -m venv venv
source venv/bin/activate
```

验证虚拟环境：

```bash
python --version
pip --version
```

建议 Python 版本 >= 3.10。

## 3. 安装依赖

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 常见依赖安装问题

问题：windows 下安装 bcrypt 报错
解决：安装 Microsoft Visual C++ Build Tools 或使用 pip install bcrypt --no-build-isolation

问题：transformers/sentence-transformers 下载慢
解决：配置国内镜像源
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

问题：FlagEmbedding 安装失败
解决：确保 torch 已安装，建议先安装 PyTorch（CPU 版约 2GB）
```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

## 4. 启动 Redis（可选）

### Windows（使用 WSL）

```bash
# 安装 Redis
sudo apt-get install redis-server

# 启动 Redis
sudo service redis-server start

# 验证
redis-cli ping
# 应返回 PONG
```

### Docker 方式

```bash
docker run -d --name rag_redis -p 6379:6379 redis:alpine redis-server --appendonly yes
```

### 不使用 Redis

系统会自动检测 Redis 连接状态。如果 Redis 不可用，会自动切换到内存存储模式，聊天历史和会话数据保存在 Python 进程内存中。重启服务后数据会丢失。

## 5. 配置环境变量

复制 .env 文件并根据实际情况修改：

```bash
cp .env .env.local
# 编辑 .env.local 或直接修改 .env
```

### 必须配置的项

```ini
# DeepSeek API 密钥（必须配置，否则 AI 无法回复）
MODEL_API_KEY=sk-your-deepseek-api-key

# 本地嵌入模型路径（如果使用本地模型）
BGE_M3_PATH=D:/BGE-M3
BGE_RERANKER_PATH=D:/重排序模型/bge-reranker-base

# MySQL 密码（如果使用 MySQL）
MYSQL_PASSWORD=your_password_here
```

## 6. 验证安装

运行启动测试脚本：

```bash
# 确保虚拟环境已激活
python test_startup.py
```

脚本会依次测试：配置加载 -> FastAPI 创建 -> Redis 客户端 -> MySQL 客户端 -> Milvus 客户端 -> 认证服务 -> 角色服务 -> 知识库服务 -> 聊天服务 -> LLM 模型。

期望看到 "所有模块加载成功!" 输出（个别服务连接失败但降级成功也算通过）。

## 7. 启动服务

```bash
uvicorn main:app --host 0.0.0.0 --port 8080 --reload
```

或使用快捷启动：

```bash
python main.py --host 0.0.0.0 --port 8080 --reload
```

启动后访问 http://localhost:8080 即可看到首页。

## 8. Docker 部署

一键启动全套服务（需安装 Docker Desktop）：

```bash
docker compose up -d
```

包含：Nginx（负载均衡）+ 3 个后端实例 + Redis + Milvus + etcd + MinIO。
