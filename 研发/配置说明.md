# 配置说明

## 配置文件位置

项目根目录的 `.env` 文件。系统启动时由 `config/settings.py` 自动读取。

## 配置项完整列表

### 大模型配置 (ModelSettings)

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| MODEL_TYPE | online | 模型类型。online=在线API, local=本地模型（预留） |
| MODEL_API_KEY | (空) | DeepSeek API 密钥。**必须配置**，否则 AI 无法回复 |
| MODEL_ENDPOINT | https://api.deepseek.com/v1/chat/completions | API 端点地址。兼容 OpenAI 格式的 API 都可使用 |
| TEMPERATURE | 0.7 | 生成温度。0.0-2.0，值越大回复越随机。建议 0.3-0.8 |
| MAX_TOKENS | 2048 | 最大生成 token 数。控制回复长度 |

### 数据库配置 (DatabaseSettings)

#### MySQL 配置

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| MYSQL_HOST | localhost | MySQL 服务器地址 |
| MYSQL_PORT | 3306 | MySQL 端口 |
| MYSQL_USER | root | MySQL 用户名 |
| MYSQL_PASSWORD | (空) | MySQL 密码。按实际密码填写 |
| MYSQL_DATABASE | rag_chat | 数据库名称，不存在时自动创建 |

如果不使用 MySQL，保持默认即可，系统会自动降级到内存存储。

#### Redis 配置

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| REDIS_HOST | localhost | Redis 服务器地址 |
| REDIS_PORT | 6379 | Redis 端口 |
| REDIS_DB | 0 | Redis 数据库编号（0-15） |

如果不使用 Redis，保持默认即可，系统会自动降级到内存存储。

#### Milvus 配置

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| MILVUS_HOST | localhost | Milvus 服务器地址 |
| MILVUS_PORT | 19530 | Milvus 端口 |
| MILVUS_COLLECTION | rag_chatbot | Milvus 集合名称 |

如果不使用 Milvus，保持默认即可，系统会自动降级到内存向量检索。

### 向量模型配置 (EmbeddingSettings)

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| BGE_M3_PATH | D:/BGE-M3 | BGE-M3 嵌入模型的本地路径。需要先下载模型文件 |
| BGE_RERANKER_PATH | D:/重排序模型/bge-reranker-base | BGE-Reranker 重排序模型的本地路径 |
| EMBEDDING_DIM | 1024 | 嵌入向量维度。BGE-M3 稠密向量为 1024 维 |
| EMBEDDING_MODEL_TYPE | bge_m3 | 嵌入模型类型。当前仅支持 bge_m3 |
| USE_LOCAL_EMBEDDING | true | 是否使用本地嵌入模型。false=使用关键词匹配降级方案 |

**关于本地嵌入模型**：

BGE-M3 和 BGE-Reranker 模型需要从 HuggingFace 下载：
```bash
# 下载 BGE-M3 (约 2.2GB)
git lfs install
git clone https://huggingface.co/BAAI/bge-m3 D:/BGE-M3

# 下载 BGE-Reranker (约 1.1GB)
git clone https://huggingface.co/BAAI/bge-reranker-base D:/重排序模型/bge-reranker-base
```

如果磁盘空间或网络条件不允许，可设置 `USE_LOCAL_EMBEDDING=false`，系统将使用 jieba 分词 + 关键词匹配作为降级检索方案。

### 应用配置 (AppSettings)

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| APP_NAME | RAG多角色智能聊天机器人 | 应用名称，显示在页面标题和启动日志 |
| APP_VERSION | 2.0.0 | 应用版本号 |
| DEBUG | false | 调试模式开关。true=输出更多调试日志 |
| HOST | 0.0.0.0 | 服务监听地址。0.0.0.0=所有网络接口 |
| PORT | 8080 | 服务监听端口 |

### 知识库配置 (KnowledgeSettings)

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| KNOWLEDGE_DIR | text_data | 知识库文件目录（相对项目根目录） |
| TOP_K | 5 | 检索时返回的最大知识条目数 |
| HYBRID_WEIGHT | 0.7 | 混合检索中向量检索的权重（0-1） |
| BM25_WEIGHT | 0.3 | 混合检索中 BM25 关键词检索的权重（0-1） |
| RERANK_TOP_N | 3 | 重排序后返回的最多条目数 |

**混合检索权重说明**：
- `HYBRID_WEIGHT` + `BM25_WEIGHT` 不一定等于 1，但建议设置总和为 1
- 向量检索适合语义匹配（同义词、近义词）
- BM25 适合精确关键词匹配
- 建议 HYBRID_WEIGHT=0.7, BM25_WEIGHT=0.3

## 示例 .env 文件

```ini
# 大模型配置
MODEL_TYPE=online
MODEL_API_KEY=sk-your-api-key-here
MODEL_ENDPOINT=https://api.deepseek.com/v1/chat/completions
TEMPERATURE=0.7
MAX_TOKENS=2048

# Milvus配置
MILVUS_HOST=localhost
MILVUS_PORT=19530
MILVUS_COLLECTION=rag_chatbot

# Redis配置
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_DB=0

# MySQL配置
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=your_password
MYSQL_DATABASE=rag_chatbot

# 向量模型配置（本地模型路径）
BGE_M3_PATH=D:/BGE-M3
BGE_RERANKER_PATH=D:/重排序模型/bge-reranker-base
EMBEDDING_DIM=1024
EMBEDDING_MODEL_TYPE=bge_m3
USE_LOCAL_EMBEDDING=true

# 知识库检索参数
TOP_K=5
HYBRID_WEIGHT=0.7
BM25_WEIGHT=0.3
RERANK_TOP_N=3

# 应用配置
APP_NAME=RAG多角色智能聊天机器人
APP_VERSION=2.0.0
DEBUG=false
HOST=0.0.0.0
PORT=8080
```

## 配置优先级

系统按以下优先级读取配置：
1. 环境变量（最高）
2. .env 文件
3. 代码中的默认值（最低）

## 常见配置问题

### 模型 API 连接失败
确认 MODEL_API_KEY 有效，MODEL_ENDPOINT 可访问（检查网络/代理）。

### 本地嵌入模型加载失败
确认 BGE_M3_PATH 和 BGE_RERANKER_PATH 指向正确的模型目录，包含必要的模型文件（config.json, pytorch_model.bin 等）。

### 数据库连接失败
系统会自动降级到内存模式，功能不受影响但重启会丢失数据。如需持久化，请确保 MySQL/Redis 服务已启动。

### 向量检索不返回结果
确认知识库文件 (text_data/*.txt) 存在且非空，调用 `/knowledge/reload` 重新加载。
