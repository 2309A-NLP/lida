# 本地部署指南

本文档详细介绍如何在本地环境中从零开始部署 RAG 多角色智能聊天机器人系统。

## 环境要求

### 硬件要求

| 组件 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | 4 核 | 8 核及以上 |
| 内存 | 8 GB | 16 GB 及以上 |
| 磁盘 | 10 GB 可用空间 | 20 GB SSD |
| GPU（可选） | - | NVIDIA GPU 8GB+（本地 Embedding 模型加速） |

### 软件要求

| 软件 | 版本要求 |
|------|---------|
| Python | 3.9 - 3.11 |
| pip | 21.0+ |
| Redis（可选） | 6.0+ |
| MySQL（可选） | 8.0+ |
| Git | 2.0+ |

## 完整部署步骤

### 第一步：克隆项目

```bash
git clone <项目仓库地址>
cd RAG_多角色智能聊天机器人项目
```

### 第二步：创建 Python 虚拟环境

**Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

验证虚拟环境已激活（命令行前缀应显示 `(venv)`）：

```bash
which python  # Linux/macOS
where python  # Windows
```

### 第三步：安装 Python 依赖

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

如果安装速度慢，可使用国内镜像：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**注意**: `sentence-transformers` 和 `transformers` 可能会下载较大的模型文件，首次安装可能需要较长时间。

### 第四步：配置环境变量

复制 `.env` 文件并根据实际环境修改：

```bash
# 编辑 .env 文件
vi .env  # 或使用任何文本编辑器
```

关键配置项说明：

```ini
# 大模型配置（必填）
MODEL_TYPE=online                    # online: 在线API, local: 本地模型
MODEL_API_KEY=sk-xxxx                # API Key（在线模式必填）
MODEL_ENDPOINT=https://api.deepseek.com/v1/chat/completions

# Milvus 配置（可选，如不使用可注释掉）
MILVUS_HOST=localhost
MILVUS_PORT=19530
MILVUS_COLLECTION=rag_chatbot

# Redis 配置（可选，如不使用可注释掉）
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_DB=0

# MySQL 配置（可选，如不使用可注释掉）
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=your_password_here
MYSQL_DATABASE=rag_chatbot

# 向量模型配置
EMBEDDING_MODEL=BAAI/bge-m3
RERANK_MODEL=BAAI/bge-reranker-large
EMBEDDING_MODEL_TYPE=simple
USE_LOCAL_EMBEDDING=false

# 应用配置
APP_NAME=RAG角色扮演系统
APP_VERSION=1.0.0
DEBUG=True           # 生产环境请设为 False
```

### 第五步：启动可选依赖服务

#### 启动 Redis（可选）

如果使用会话缓存或短期记忆功能，需要启动 Redis：

**使用 Docker 启动（推荐）:**

```bash
docker run -d --name rag-redis -p 6379:6379 redis:alpine redis-server --appendonly yes
```

**直接安装启动:**

```bash
# Ubuntu/Debian
sudo apt install redis-server
sudo systemctl start redis

# macOS
brew install redis
brew services start redis
```

验证 Redis 连接：

```bash
redis-cli ping
# 应返回: PONG
```

#### 启动 MySQL（可选）

如果使用用户管理、角色信息持久化功能，需要启动 MySQL：

**使用 Docker 启动（推荐）:**

```bash
docker run -d --name rag-mysql \
  -e MYSQL_ROOT_PASSWORD=your_password_here \
  -e MYSQL_DATABASE=rag_chatbot \
  -p 3306:3306 \
  mysql:8.0
```

**手动创建数据库:**

```sql
CREATE DATABASE IF NOT EXISTS rag_chatbot CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 启动 Milvus（可选）

如果使用向量检索功能，需要启动 Milvus：

**使用 Docker 启动（推荐）:**

```bash
# 拉取 Milvus 镜像
docker pull milvusdb/milvus:v2.3.3

# 启动 Milvus（需同时启动 etcd 和 minio）
# 简化方式，使用项目自带的 docker-compose.yml 中的 milvus 服务
# 或参考 Milvus 官方文档: https://milvus.io/docs/install_standalone-docker.md
```

### 第六步：启动应用

```bash
# 确保虚拟环境已激活
python main.py --host 0.0.0.0 --port 8080
```

启动成功后，终端输出示例：

```
============================================================
      RAG角色扮演系统
      版本: 1.0.0
      地址: http://0.0.0.0:8080
============================================================
INFO:     Started server process [12345]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8080 (Press CTRL+C to quit)
```

### 第七步：验证部署

打开浏览器访问：

- 主页：http://localhost:8080/
- 角色选择：http://localhost:8080/characters.html
- 聊天页面：http://localhost:8080/chat.html
- 系统架构：http://localhost:8080/architecture.html
- 健康检查：http://localhost:8080/health

## 开发模式（热重载）

开发时建议开启热重载，代码修改后自动重启：

```bash
python main.py --host 0.0.0.0 --port 8080 --reload
```

## 停止应用

按 `Ctrl + C` 停止应用。如果启动了后台服务，也需相应停止：

```bash
# 停止 Docker 容器
docker stop rag-redis rag-mysql

# 或停止系统服务
sudo systemctl stop redis
```
